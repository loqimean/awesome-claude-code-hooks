# Contributing

Thanks for considering a contribution! Please check the following before opening a PR:

## Inclusion criteria

- The project must be about **Claude Code hooks** specifically (not just Claude Code in general) — either a hook implementation, a guide focused on hooks, or a toolkit where hooks are a first-class, documented feature.
- Must have a public repo with a README explaining what it does and how to install/use it.
- Prefer actively maintained projects (a commit or release within the last ~6 months) — dead links get pruned.
- No pure self-promotion / affiliate-link projects. No paywalled content as the primary entry.

## How to add an entry

1. Fork the repo.
2. Add your entry to the most relevant section, alphabetically within the section, in this format:

   ```md
   - [owner/repo](https://github.com/owner/repo) — one clear sentence: what it does and why it's useful.
   ```

3. If no existing section fits, propose a new one in your PR description.
4. Run a spell-check on your addition.
5. Open a PR with a short description of the project and why it belongs here.

## Removing entries

If you spot a dead link, an archived/abandoned repo, or something that no longer fits, open a PR removing it (or flag it in an issue).
